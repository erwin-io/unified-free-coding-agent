---
name: angular-node-development
description: Work on Angular standalone applications with Node.js backend REST APIs.
---
Read existing Angular version, angular.json, package.json, TypeScript configs
and API contracts. Prefer Angular CLI for generate/build/test operations.
Use standalone components and documented public APIs for the installed version.
Preserve frontend proxy configuration, routing and API error handling.
Validate Node backend APIs, TypeScript / Angular production builds, and
relevant frontend tests where present. Do not change providers, SSR or
architecture silently. Never report tests passed unless exit status observed.
