# Angular + Node.js full-stack starter

- `frontend/`: Angular standalone app generated by the official CLI.
- `backend/`: Node.js REST API using built-in HTTP (no database).
- `scripts/dev.mjs`: launches both. UI: http://localhost:4200; API: http://127.0.0.1:3001.
- Angular dev proxy forwards `/api` calls to the backend.
- No database and no paid cloud service.

```powershell
npm run dev
npm run test
npm run lint
npm run typecheck
```

The first scaffold invokes Angular CLI over npm. Requires Node.js and internet.
The frontend's Angular project and package lock are generated by the CLI.
The API health indicator uses `/api/health` through Angular's development proxy.
