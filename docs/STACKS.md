# Supported project types and boundaries

The same router, task supervisor, history and agent handoff state work with any
language. PROJECT_PATH selects the repository to edit. PROJECT_STACK selects
the scaffold **only for a new directory**. Existing repositories are preserved.

## Stack selection
Set one of the following in .env, then run .\run.ps1 once:

| PROJECT_STACK | New project | Local validation |
| --- | --- | --- |
| node-web | Node.js + HTML/CSS/JavaScript | Node built-in test runner and syntax checks |
| angular-node | Angular CLI standalone frontend + Node.js REST backend | Backend tests, Node syntax and Angular production build |
| micropython | MCU MicroPython source, host tests and optional serial tools | CPython unittest and syntax compilation; board-specific runtime validation separate |
| cpp | Modern C++17 with CMake, library and CTest executable | Configure, build and CTest on native compiler |

Example on Windows:
1. Set PROJECT_PATH=C:\Development\my-angular-project
2. Set PROJECT_STACK=angular-node
3. powershell -ExecutionPolicy Bypass -File .\run.ps1

Or override the selected stack just for that run:
powershell -ExecutionPolicy Bypass -File .\run.ps1 -Stack cpp

Never run a scaffold against a target already containing an initialized Git repo:
the agent will open it as-is and inspect its current source/standards.

## Prerequisites

Common: Python 3.10+, Git, Node.js/npm for OpenCode, VS Code recommended.
Node-web: Node 20+.
Angular-node: Angular v22 requires Node.js ^22.22.3 or ^24.15.0 or ^26.0.0; npx and internet are needed to download @angular/cli and dependencies. The scaffold checks this before creating files.
MicroPython: Python only for host tests. Physical board interaction requires compatible MicroPython firmware, a USB serial connection and the optional mpremote package. Never upload or erase automatically.
C++: CMake 3.20+, CTest and a working C++ compiler such as MSVC Build Tools, Clang or GCC. For ESP32/Arduino/RP2040 firmware, choose a particular board and install its compiler/toolchain or PlatformIO. No generic C++ binary can be flashed universally.

## Validation and safety

The independent supervisor runs configured commands in project/.agent/validation.json
or discovers project scripts. MicroPython and C++ templates include their checks.
Angular and Node projects include npm scripts.

Actual hardware execution, flash writes, bootloader programming, serial port
selection and electrical pin decisions require human approval. All firmware
operations must respect the real board voltage, pinout and bootloader.

The first run must pass the host build and tests before the code is approved.
If prerequisites aren't installed, the scaffold stops with a clear error and
preserves existing data; it doesn't invent a successful build.

The Angular CLI project is generated by the official Angular tool rather than
shipping a stale checked-in node_modules directory. This first-time operation
requires internet, and its full Windows live integration has to be verified.
